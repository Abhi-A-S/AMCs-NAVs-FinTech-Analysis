# AMCs-NAVs-FinTech-Analysis

Analysis of Net Asset Values (NAVs) of Asset Management Companies (AMCs) in the FinTech sector based on historical data. This project aims to provide insights into the performance and trends of various AMCs by analyzing their NAVs over time.

## Handling the dataset

The dataset used in this analysis is sourced from publicly available financial records of AMCs which are stored in dsf format in the `./dataset` directory. The dataset contains historical NAVs of various AMCs along with relevant metadata.

## How to use
Extract the two zip files as folders in the `./dataset` directory.
